# Zenora by QuantsLab

A workspace for creating images, keeping variations together, and sharing selected work.

[Open Zenora](https://zenora.dev) · [Studio](https://studio.zenora.dev) · [Get the Android app](https://zenora.dev/download)

## The platform

| Product | What it does |
|---|---|
| **Studio** | Image creation, references, camera views and a private library |
| **Discover** | Community images and contributions shared with consent |
| **Access** | Accounts, invitations and secure application sign-in |
| **Render** | Queued generation, live previews and GPU workers |
| **Pulse** | Requests, pipeline errors and infrastructure observations |
| **Post** | Email delivery and provider configuration |
| **Mobile** | One Android/iOS codebase; Android is available today |

## Building with Zenora

The [developer guide](https://github.com/QuantsLab-Zenora/zenora-developers) covers the versioned API, OAuth with PKCE, live progress and native application integration. Implementation repositories are private.

Contributors start with the private **zenora-platform** service catalog. Applications and services have separate build targets and release artifacts so fixes can ship independently.
